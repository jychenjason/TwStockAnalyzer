# 不做還原股價，改以標記除權息日

Replay 一律以**原始成交價**顯示與計價，不使用還原股價；除權息當日改在 K 線圖上標記。取得還原價需要新增股利與配股資料源並回填全部歷史，是一個獨立專案；更關鍵的是還原後的價格與使用者當年在盤面上看到的數字不符，違背回放「重現當時所見」的目的。

## Consequences

持股跨過除權息日時，帳面會憑空少一段（等同沒收到股利），因此圖上的標記是必要的，否則那根跳空會被誤讀成崩盤。

現有 `daily_prices.adj_close` 欄位是**假的**：25 萬筆資料中沒有任何一筆與 `close` 不同，它從未做過任何還原。此欄位不得被當作還原價使用；沉默地假裝自己是還原價，比明確不提供更危險。
