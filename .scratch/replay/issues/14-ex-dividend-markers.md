# 14 — 除權息標記

**What to build:** K 線圖上標記出除權息交易日。系統一律使用原始成交價、不做還原（見 ADR 0002），所以持股跨過除權息日時帳面會憑空少一段；沒有這個標記，那根跳空會被誤讀成崩盤。

資料源已確認可用：免費資料源提供除權息交易日、除權息前後參考價、配息配股金額與除權／除息別，不需要從價格跳空反推。

**Blocked by:** 04

**Status:** done

- [x] 除權息資料可抓取並存入資料庫，含日期、金額、除權／除息別
- [x] K 線圖在除權息交易日顯示標記
- [x] 標記可看出配息或配股金額
- [x] 只標記 Cursor 當日及之前的除權息日，不洩漏未來的除權息安排
- [x] 無除權息資料的股票或期間，圖表正常顯示且無標記
- [x] 明確不使用既有的 `adj_close` 欄位——它目前是假的還原價，全部等於收盤價
- [x] 測試以含除權息日的人造資料驗證標記位置與未來除權息不外洩
