# 07 — 買進：次日開盤成交

**What to build:** 使用者在某一格送出買進 Order，該 Order 在次一交易日以開盤價成為 Fill，扣除券商手續費，畫面顯示目前的 Position、現金與未實現損益。若次日開盤跳空導致現金不足，該筆 Order 整筆作廢並標記原因，不自動減量、不允許負現金。

成交價的選擇見 ADR 0001：使用者是在看完當日收盤 K 棒後按下的按鈕，以當日收盤價成交等同拿到決策當下不可能拿到的價格。

**Blocked by:** 04

**Status:** done

- [x] 使用者可在 Cursor 當日送出以「張」為單位的買進 Order
- [x] Order 於次一交易日以該日開盤價成為 Fill，而非當日收盤價
- [x] 同一格可送出多筆 Order，全部在次一交易日一併結算
- [x] Fill 扣除券商手續費，含最低 20 元下限與可設定的折數
- [x] 現金不足時該筆 Order 整筆作廢並記錄原因，現金與 Position 不變
- [x] 畫面顯示目前 Position 股數、加權平均成本、現金餘額、未實現損益
- [x] Order 與 Fill 存入資料庫，重新載入 Session 後紀錄完整
- [x] 交易成本計算獨立成可單獨驗證的單元
- [x] 不提供限價單與委託有效期——只有四個價位的日 K 無法支撐觸價判定
- [x] 測試以含跳空開盤的人造價格序列驗證成交價與資金不足的作廢路徑

## Comments

- 新增 `replay/costs.py`（手續費 0.1425%、最低 20 元、可打折；證交稅 0.3%）與 replay_orders 表。
- 委託一律於次一交易日開盤成交（ADR 0001）。測試資料的 open 與 close 刻意不同，否則無法分辨成交價取自哪一天的哪個欄位。
- 資金不足整筆作廢並記錄原因；真實資料實測到這條路徑：2330 一張 113 萬，100 萬初始資金買不起，正確作廢。
- 金額四捨五入改用 Decimal ROUND_HALF_UP，不用內建 round()——後者是銀行家捨入，會出現 712.5→712 但 713.5→714 的不一致。
