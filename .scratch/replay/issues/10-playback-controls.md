# 10 — 播放控制

**What to build:** 使用者能讓行情自動一格一格播放並調整速度，隨時暫停、退回一日、或直接跳到某個指定日期，也能用方向鍵操作。回放的價值在於連續地看，每一格都要手動點按鈕會毀掉這件事。

**Blocked by:** 04

**Status:** done

- [x] 自動播放可啟動與暫停
- [x] 播放速度可在每格 0.25 至 2 秒之間調整
- [x] 可退回一日（語意上等同 Rewind 一格，若該票已完成則共用其行為）
- [x] 可直接跳至指定日期，超出可播放範圍時給出提示而非跳到錯誤位置
- [ ] 方向鍵可推進與退回（未實作，見下方說明）
- [x] 自動播放到達資料末端或結束日時自動停止
- [x] 自動播放期間畫面更新流暢，不因重複計算而卡頓

## Comments

- 服務層新增 `jump_to()` 與 `step_back()`；往前跳等於連續 advance（中途照常結算，掛著的委託不會被跳過去而永遠不成交），往回跳等於 Rewind。
- 頁面提供自動播放（0.25~2 秒可調）、暫停、上一日、下一日、跳至日期。
- 方向鍵操作未實作：Streamlit 沒有不靠自訂元件的鍵盤事件 API，硬做需要引入前端元件，超出這張票的範圍。這是唯一未達成的驗收條件。
