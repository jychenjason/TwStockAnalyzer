# 06 — 籌碼面板

**What to build:** 使用者在回放中看到三大法人買賣超隨 Cursor 一天一天呈現，能把籌碼動向納入判斷。當某日沒有籌碼資料時，畫面顯示「無資料」，而不是畫成 0——把資料缺口畫成 0 會被誤讀成法人當天沒有進出，那是假訊號。

**Blocked by:** 04

**Status:** done

- [x] 籌碼面板只呈現 Cursor 當日及之前的資料
- [x] 無籌碼資料的日期顯示為「無資料」，與真實的 0 買賣超可區分
- [x] 起始日早於籌碼資料涵蓋範圍時，面板整體顯示提示而非空白圖表
- [x] 面板隨 Cursor 推進同步更新
- [x] 測試以含缺口的人造籌碼資料驗證缺口不被填成 0

## Comments

- 服務層新增 `visible_institutional()` / `institutional_at()` / `institutional_coverage()`。
- 「無資料」與「真的是 0」在服務層就分得開：`institutional_at()` 缺資料回 None，不回一列 0。測試資料刻意安排一天真正的 0 買賣超與一天缺資料。
- 真實資料實測：2025 年的回放日期落在籌碼資料涵蓋範圍（2026-01 起）之外，面板正確顯示無資料而非畫成 0。
