# 08 — 賣出與損益

**What to build:** 使用者能分批賣出持股，成交同樣落在次一交易日開盤，扣除手續費與證券交易稅，並看到這一趟的已實現損益。成本以加權平均計算——這是使用者在真實券商對帳單上看到的數字，練習器應該與它一致。

**Blocked by:** 07

**Status:** done

- [x] 使用者可賣出全部或部分持股
- [x] 賣出 Fill 於次一交易日開盤價成交
- [x] 賣出扣除手續費與證券交易稅
- [x] 已實現損益以加權平均成本計算，非先進先出
- [x] 分批買進後部分賣出，剩餘 Position 的加權平均成本維持正確
- [x] 持股不足時該筆賣單整筆作廢並記錄原因
- [x] 賣出後現金、Position、累計已實現損益同步更新並存檔
- [x] 測試涵蓋分批買進後部分賣出、全部賣出、以及持股不足的作廢路徑

## Comments

- 賣出扣手續費與證交稅，成本以加權平均計算，部分賣出後平均成本不變。
- 誠實記錄：賣出分支與加權平均扣減是在票 07 的結算迴圈裡一併寫下的，所以這張票的測試是後補的守門測試，不是驅動實作的紅燈。
