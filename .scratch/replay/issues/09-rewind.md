# 09 — Rewind：把時間線截斷重來

**What to build:** 使用者按錯或想重試某一段時，能把 Cursor 退回較早的交易日。退回會連同該日之後的所有 Order 與 Fill 一併作廢，帳戶狀態等同於那些單從未存在過——否則會出現「已退回三月卻持有五月成交部位」的時間悖論。執行前必須明確告知會失去什麼。

**Blocked by:** 08

**Status:** done

- [x] 使用者可將 Cursor 退回任一較早的交易日
- [x] 執行前顯示確認提示，說明將作廢幾筆交易
- [x] 退回後該日之後的所有 Order 與 Fill 消失
- [x] 退回後的現金、Position、加權平均成本、已實現損益，與「從未下過那些單」的狀態完全一致
- [x] 帳戶狀態由剩餘交易紀錄重新推導，而非另存快照
- [x] 退回後可正常繼續推進與下單
- [x] 測試驗證「下單→推進數日→退回→重新推進」後的狀態，與「直接推進到同一天」完全相同

## Comments

- 倒退到 D 的語意定為「回到 D 這天重新決定」：D 當天（含）之後送出的委託全部消失；D 之前送出、在 D 開盤成交的委託保留，因為那筆成交發生在 D 的任何決定之前。
- 這個語意是被兩條互相矛盾的測試逼出來的——原本我同時寫了「D 當天的委託退回未成交」與「D 當天的委託一併作廢」。選後者：語意單一、好解釋，也避免出現使用者難以理解的半掛單狀態。
- 帳戶狀態一律由剩餘委託重新推導，不存快照。等價性測試：倒退後重播 == 從未下過那些單。
